## 首次订阅

1. 打开 MoveTogether，前往 **设置 → 订阅**（或在你尝试使用 Pro 功能时出现的升级提示）。
2. 你会看到 Pro 套餐及其定价与功能列表。
3. 选择你的计费周期（月度或年度）。
4. 通过 App Store 确认你的购买。你可能需要用面容 ID、触控 ID 或 Apple ID 密码完成认证。
5. 你的套餐立即生效，Pro 功能马上解锁。

## 网页购买

你也可以通过我们的网站 [movetogetherfitness.com](https://movetogetherfitness.com) 订阅。这是一条替代的购买路径，价格可能不同。无论你在哪里购买，你的订阅都会自动同步到 App。

## 介绍价

如果你看到介绍价或促销价，会在购买前显示在订阅界面上。介绍价仅适用于新订阅者，促销期结束后将以标准价续费。

## 免费试用

MoveTogether 可能不时提供 Pro 套餐的免费试用。如果有试用可用，你会在订阅界面上看到。除非你在试用期结束前取消，否则试用会在试用期结束时自动转为付费订阅。
