## サブスクライブしたが、機能がまだロックされている

1. MoveTogether を強制的に閉じて再度開き、サブスクリプションステータスチェックをトリガーします。
2. 1 〜 2 分待ちます。App Store が購入を確認してアプリがそれを認識するまでに短い遅延がある場合があります。
3. **設定 → サブスクリプション** でサブスクリプションステータスを確認します。
4. **設定 → サブスクリプション** で **購入を復元** をタップします。
5. Apple 側でサブスクリプションがアクティブであることを確認します:**iPhone 設定 → [あなたの名前] → サブスクリプション**。

サブスクリプションがアクティブであることを確認したが機能がまだロックされている場合は、[movetogetherfitness.com](https://movetogetherfitness.com) で Mo とチャットしてください。

## 課金されたがサブスクリプションが見えない

- 購入に使用したのと同じ Apple ID でサインインしていることを確認します。
- **購入を復元** ボタンを試します。

問題が続く場合は、Apple ID と料金のスクリーンショットで [movetogetherfitness.com](https://movetogetherfitness.com) の Mo とチャットしてください。
