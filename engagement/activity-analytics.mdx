title: "Read activity, sleep, weight, and BMI trends"
description: "Use activity chart periods and detail values, understand missing sleep data, and log weight or set height on iPhone."
---

Daily activity tracking is available on Free. Pro adds the trend charts for activity, sleep, weight, and BMI. These screens describe fitness data; they do not diagnose a condition.

## Open your analytics

On iPhone, open **Profile → Today's Activity**. Review the daily activity summary, then scroll to the charts. If you see an analytics upgrade card, the chart area requires Pro; this does not mean basic activity tracking is unavailable.

## Choose a period for each chart

Charts have their own period selectors: day, week, month, six months, or year. Changing one chart does not require every other chart to use the same period.

1. Find the metric or chart you want to understand.
2. Select a period.
3. Tap a plotted value to inspect its detail.
4. Compare the selected date or bucket with the summary and units displayed.

Longer periods can group values into averages rather than showing every reading. Read the chart's summary label before interpreting a bar as a single day.

**Example:** keep Activity on a week to compare recent days while using a month for Sleep. A daily activity total and a multi-day average answer different questions, even if their numbers appear close.

## Sleep

Sleep appears when a connected source supplies it and the necessary access is granted. The chart can show stages and duration, but not every device provides every stage.

An empty chart is not a report that you slept zero hours. Check the selected period, the source's own app, and the relevant permission. If Apple Health offers a connection prompt for sleep from your device, follow that prompt only if you want to enable the Health path.

## Log today's weight

1. In the activity detail screen, find **Weight** and tap its add/log control.
2. In **Log today's weight**, choose **lbs** or **kg**.
3. Adjust the value using the scale control.
4. Tap **Save**.

The saved entry updates the weight chart and current weight on Profile. This sheet records today's value; it is not an editor for every historical reading in your connected service. If you need help correcting a stored entry, [contact Marco](/troubleshooting/contact-support) rather than assuming a provider record was changed.

## Height and BMI

The BMI card needs both weight and height. If it shows **Set your height to see BMI**, tap that prompt and save your height. Use the card's displayed current value and trend as general reference information, not a diagnosis or a personalized health recommendation.

## Missing or unexpected values

| Symptom | First check |
| --- | --- |
| An entire period is empty | Choose dates with known activity and check the source has synced. |
| One metric is absent | Confirm the provider records it and MoveTogether has access. |
| Different devices disagree | Review your [primary activity source](/getting-started/primary-activity-source). |
| Exercise differs from session duration | Read the [workout-crediting explanation](/troubleshooting/sync-issues#my-workouts-sync-but-my-exercise-ring-looks-different). |

For a spreadsheet to review outside the app, use [Export an activity report](/engagement/export-activity-report). It is available on Free and Pro and is separate from the Pro chart interface.
