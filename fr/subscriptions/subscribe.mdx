## S'abonner pour la première fois

1. Ouvrez MoveTogether et allez dans **Réglages → Abonnement** (ou appuyez sur l'invite de mise à niveau qui apparaît quand vous essayez d'utiliser une fonctionnalité Pro).
2. Vous verrez le plan Pro avec les tarifs et les fonctionnalités listées.
3. Choisissez votre période de facturation (mensuelle ou annuelle).
4. Confirmez votre achat via l'App Store. Vous devrez peut-être vous authentifier avec Face ID, Touch ID ou votre mot de passe d'identifiant Apple.
5. Votre plan est actif immédiatement et les fonctionnalités Pro se débloquent tout de suite.

## Achat sur le web

Vous pouvez aussi vous abonner via notre site web sur [movetogetherfitness.com](https://movetogetherfitness.com). Un parcours d'achat alternatif qui peut avoir des tarifs différents. Votre abonnement se synchronise automatiquement avec l'application, quel que soit l'endroit où vous l'avez acheté.

## Tarif d'introduction

Si vous voyez un tarif d'introduction ou promotionnel, il est affiché sur l'écran d'abonnement avant l'achat. Les tarifs d'introduction s'appliquent uniquement aux nouveaux abonnés et se renouvellent au tarif standard après la période promotionnelle.

## Essai gratuit

MoveTogether peut proposer des essais gratuits du plan Pro de temps en temps. Si un essai est disponible, vous le verrez sur l'écran d'abonnement. Votre essai se convertit en abonnement payant à la fin de la période d'essai sauf si vous annulez avant.
