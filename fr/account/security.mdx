## Se connecter

MoveTogether prend en charge deux méthodes de connexion :

**Se connecter avec Apple.** Utilise votre Apple ID pour une authentification sécurisée et sans mot de passe. Apple peut aussi masquer votre e-mail pour une confidentialité supplémentaire.

**Se connecter avec Google.** Utilise votre compte Google pour une connexion rapide et sécurisée.

## Garder votre compte sécurisé

- Utilisez Se connecter avec Apple ou Google pour l'expérience la plus sécurisée. Ils utilisent l'authentification biométrique de votre appareil.
- Ne partagez pas vos identifiants de compte avec qui que ce soit.
- Ne partagez pas d'informations sensibles dans le chat Coach Mo ou les chats de groupe de compétition.

## Se déconnecter

Allez dans **Paramètres** et faites défiler jusqu'à appuyer sur **Se déconnecter**.

## Changer d'appareil

Téléchargez MoveTogether sur votre nouvel appareil, connectez-vous avec le même compte, et reconnectez votre tracker fitness dans **Paramètres → Appareils connectés**. Votre historique de compétitions, récompenses, amis et toutes les autres données se synchronisent automatiquement.

## Si vous pensez que votre compte a été compromis

1. Déconnectez-vous immédiatement.
2. Examinez les paramètres de sécurité de votre Apple ID ou compte Google.
3. Discutez avec Mo sur [movetogetherfitness.com](https://movetogetherfitness.com) et commencez votre message par « Sécurité : » pour signaler le problème.
