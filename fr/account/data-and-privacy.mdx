## Quelles données MoveTogether collecte

**Informations de compte.** Votre nom, adresse e-mail, nom d'utilisateur et photo de profil, fournis par vous lors de la création de votre compte.

**Données fitness.** Pas, calories actives, minutes d'exercice et informations d'entraînement, synchronisés depuis votre tracker connecté.

**Données de compétition.** Vos scores de compétition, classements et historique de participation.

**Données d'usage.** Analyses anonymes sur la façon dont vous utilisez l'app, utilisées pour améliorer MoveTogether. Vous pouvez vous désinscrire dans **Réglages → Confidentialité**.

## Comment vos données fitness sont gérées

MoveTogether stocke vos données fitness sur nos serveurs pour alimenter les fonctionnalités principales de l'app : classements, compétitions, fils d'activité, récompenses, etc. Pour les utilisateurs Apple Watch, les données sont lues depuis Apple Santé sur votre appareil et envoyées à nos serveurs. Pour les autres trackers, les données sont synchronisées depuis les serveurs du fournisseur du tracker via des connexions OAuth par l'intermédiaire de notre partenaire d'intégration, OpenWearables.

Les scores de compétition sont calculés côté serveur pour la sécurité et l'équité. Vos données de santé restent dans Apple Santé (ou dans la plateforme de votre tracker) comme source de vérité originale. MoveTogether les lit. Nous ne les modifions jamais.

## Qui peut voir vos données ?

Les participants à une compétition peuvent voir vos statistiques liées à la compétition dans le classement, sous réserve de vos paramètres de confidentialité. Vos amis peuvent voir votre activité dans le fil social, sous réserve de vos paramètres de confidentialité. Les systèmes de MoveTogether traitent vos données pour calculer les scores de compétition et générer les récompenses. Nous ne vendons jamais vos informations personnelles ni ne partageons vos données de santé brutes avec des tiers.

## Ce que voient les fournisseurs d'IA

Coach Mo et l'agent de support sont construits sur des plateformes d'IA tierces. Nous **caviardons vos informations personnelles avant qu'elles n'atteignent ces fournisseurs** — votre nom, les noms de vos amis, votre e-mail et votre nom d'utilisateur sont tous remplacés par des marqueurs avant transmission. Les fournisseurs d'IA voient vos chiffres d'activité et vos statistiques, pas qui vous êtes.

Pour le détail complet de ce fonctionnement, y compris la seule exception honnête pour la voix, voir [L'IA et vos données](/fr/account/ai-and-your-data).

## Stockage et sécurité des données

Vos données sont stockées avec un chiffrement standard de l'industrie. Toutes les connexions entre votre appareil et nos serveurs sont chiffrées. Les scores de compétition sont calculés côté serveur pour empêcher la manipulation. Notre modèle de sécurité fait que vos données ne sont accessibles que via des requêtes serveur authentifiées et validées.

## Télécharger vos données

Vous pouvez demander une copie de toutes les données que MoveTogether détient sur vous. Allez dans **Réglages → Confidentialité → Télécharger mes données**, appuyez sur le bouton pour demander une exportation, et vous recevrez un e-mail avec un lien de téléchargement quand votre exportation sera prête (généralement en 24 à 48 heures).

## Supprimer vos données

Pour supprimer votre compte et toutes les données associées, allez dans **Réglages → Confidentialité → Supprimer mon compte** (ou **Réglages → Compte → Supprimer le compte**), confirmez votre identité si demandé, puis confirmez. C'est permanent et irréversible. Toutes vos données seront supprimées.

## Services tiers

MoveTogether utilise ces services tiers pour fonctionner :

| Service | Rôle |
|---------|---------|
| Supabase | Base de données et infrastructure serveur |
| RevenueCat | Gestion des abonnements |
| OneSignal | Notifications push |
| Anthropic Claude | Alimente l'IA de Coach Mo (ne reçoit que des données anonymisées — voir [L'IA et vos données](/fr/account/ai-and-your-data)) |
| OpenWearables | Intégration des données de santé pour les trackers tiers |
| Hive | Modération de contenu (texte et image) |
| Stream | Infrastructure du fil d'activité |
| Sentry | Suivi des erreurs et surveillance des performances |
| Mixpanel | Analyses produit anonymes |

Chaque service a sa propre politique de confidentialité. Pour les détails complets, lisez notre [Politique de confidentialité](https://movetogetherfitness.com/privacy).
