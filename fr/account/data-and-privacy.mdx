## Quelles données MoveTogether collecte

**Informations de compte.** Votre nom, adresse e-mail, nom d'utilisateur et photo de profil, fournis par vous lors de la création d'un compte.

**Données fitness.** Pas, calories actives, minutes d'exercice et informations d'entraînement, synchronisés depuis votre tracker fitness connecté.

**Données de compétition.** Vos scores de compétition, classements et historique de participation.

**Données d'utilisation.** Analytics anonymes sur la façon dont vous utilisez l'app, utilisées pour améliorer MoveTogether. Vous pouvez vous désinscrire dans **Paramètres → Confidentialité**.

## Comment vos données fitness sont gérées

MoveTogether stocke vos données fitness sur nos serveurs pour alimenter les fonctionnalités principales de l'app : classements, compétitions, fils d'activité, récompenses et plus. Pour les utilisateurs Apple Watch, les données sont lues depuis Apple Santé sur votre appareil et envoyées à nos serveurs. Pour les autres trackers, les données sont synchronisées depuis les serveurs du fournisseur du tracker via des connexions OAuth à travers notre partenaire d'intégration, OpenWearables.

Les scores de compétition sont calculés côté serveur pour la sécurité et l'équité. Vos données santé restent dans Apple Santé (ou la plateforme de votre tracker) comme source de vérité originale. MoveTogether les lit. Nous ne les modifions jamais.

## Qui peut voir vos données ?

Les participants de la compétition peuvent voir vos statistiques liées à la compétition sur le classement, sous réserve de vos paramètres de confidentialité. Les amis peuvent voir votre activité dans le fil social, sous réserve de vos paramètres de confidentialité. Les systèmes de MoveTogether traitent vos données pour calculer les scores de compétition et générer des récompenses. Nous ne vendons jamais vos informations personnelles ni ne partageons vos données de santé brutes avec des tiers.

## Stockage des données et sécurité

Vos données sont stockées en utilisant un chiffrement standard de l'industrie. Toutes les connexions entre votre appareil et nos serveurs sont chiffrées. Les scores de compétition sont calculés côté serveur pour empêcher la manipulation. Notre modèle de sécurité signifie que vos données ne sont accessibles que via des requêtes serveur authentifiées et validées.

## Télécharger vos données

Vous pouvez demander une copie de toutes les données que MoveTogether possède sur vous. Allez dans **Paramètres → Confidentialité → Télécharger mes données**, appuyez sur le bouton pour demander une exportation, et vous recevrez un e-mail avec un lien de téléchargement quand votre exportation sera prête (généralement dans 24 à 48 heures).

## Supprimer vos données

Pour supprimer votre compte et toutes les données associées, allez dans **Paramètres → Confidentialité → Supprimer mon compte** (ou **Paramètres → Compte → Supprimer le compte**), confirmez votre identité si demandé, et confirmez. C'est permanent et ne peut pas être annulé. Toutes vos données seront supprimées.

## Services tiers

MoveTogether utilise ces services tiers pour fonctionner :

| Service | Objet |
|---------|---------|
| Supabase | Base de données et infrastructure serveur |
| RevenueCat | Gestion des abonnements |
| OneSignal | Notifications push |
| Anthropic Claude | Alimente l'IA Coach Mo |
| OpenWearables | Intégration des données santé pour les trackers tiers |
| Hive | Modération du contenu (texte et image) |
| Stream | Infrastructure du fil d'activité |
| Sentry | Suivi des erreurs et monitoring des performances |
| Mixpanel | Analytics produit anonymes |

Chaque service a sa propre politique de confidentialité. Pour tous les détails, lisez notre [Politique de confidentialité](https://movetogetherfitness.com/privacy).
