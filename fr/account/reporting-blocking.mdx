## Signaler un utilisateur ou un contenu

**Signaler le profil d'un utilisateur :**
1. Appuyez sur la photo de profil ou le nom de l'utilisateur pour ouvrir son profil.
2. Appuyez sur le menu d'options supplémentaires (trois points).
3. Sélectionnez **Signaler**.
4. Choisissez la raison.
5. Ajoutez des détails et appuyez sur **Envoyer**.

**Signaler un message dans le chat :**
1. Appuyez et maintenez le message que vous voulez signaler.
2. Sélectionnez **Signaler le message**.
3. Choisissez la raison et envoyez.

**Signaler une photo de profil :**
1. Appuyez sur le profil de l'utilisateur, appuyez sur le menu trois points.
2. Sélectionnez **Signaler**, choisissez **Photo de profil inappropriée** comme raison.

Vous pouvez aussi signaler des préoccupations directement en discutant avec Mo sur [movetogetherfitness.com](https://movetogetherfitness.com).

## Ce qui se passe après votre signalement

Tous les signalements sont examinés par notre équipe de modération. Votre signalement est **confidentiel**. L'autre utilisateur ne sera pas informé de qui l'a signalé. Si une infraction est confirmée, l'action de mise en application appropriée est prise.

## Bloquer un utilisateur

Appuyez sur le profil de l'utilisateur, appuyez sur le menu trois points, et sélectionnez **Bloquer l'utilisateur**. Confirmez. Quand vous bloquez quelqu'un, il ne peut pas vous envoyer de demandes d'amitié, vous inviter à des compétitions, voir votre profil ou contenu, ni vous envoyer de messages. Il n'apparaîtra pas dans vos fils, classements ou résultats de recherche. Le blocage est immédiat et l'autre utilisateur n'est pas notifié.

## Gérer les utilisateurs bloqués

Allez dans **Paramètres → Confidentialité → Utilisateurs bloqués** pour voir et débloquer des utilisateurs. Débloquer ne les ajoute pas automatiquement de nouveau comme ami.

## Bloquer vs signaler

Bloquer est un outil personnel qui empêche l'interaction. Signaler dit à notre équipe de modération d'enquêter et de protéger la communauté. Pour le meilleur résultat, faites les deux : bloquez pour vous protéger immédiatement, et signalez pour que notre équipe puisse traiter le comportement pour tout le monde.
