## Appareils pris en charge

MoveTogether fonctionne avec les plateformes fitness suivantes via OpenWearables, notre partenaire d'intégration des données de santé :

| Appareil / Plateforme | Méthode de connexion |
|------------------------|----------------------|
| Apple Watch | Apple Santé (natif sur l'appareil) |
| Fitbit | Connexion OAuth |
| Garmin | Connexion OAuth |
| WHOOP | Connexion OAuth |
| Oura Ring | Connexion OAuth |
| Strava | Connexion OAuth |
| Polar | Connexion OAuth |
| Suunto | Connexion OAuth |
| Ultrahuman | Connexion OAuth |

## Comment les connexions fonctionnent

Apple Watch se connecte via Apple Santé. MoveTogether lit vos données fitness directement depuis l'app Santé sur votre iPhone. Votre Apple Watch se synchronise avec Apple Santé de son côté, et MoveTogether lit depuis là.

Tous les autres trackers se connectent via une connexion OAuth. Vous vous connectez au compte de votre tracker depuis MoveTogether, ce qui autorise l'application à synchroniser vos données fitness. Vos identifiants ne sont jamais stockés sur nos serveurs. La connexion passe par le propre système d'autorisation de votre tracker.

## Connecter une Apple Watch

1. Ouvrez MoveTogether et allez dans **Réglages → Appareils connectés**.
2. Appuyez sur **Apple Watch**.
3. Une invite vous demande d'accorder à MoveTogether l'autorisation de lire vos données Apple Santé. Appuyez sur **Tout autoriser** (ou choisissez des catégories spécifiques).
4. Votre activité commence à se synchroniser.

<Note>
  MoveTogether a besoin d'un accès en lecture aux catégories Apple Santé incluant Pas, Énergie active (calories), Minutes d'exercice et Entraînements. Si vous refusez ces autorisations, votre activité n'apparaîtra pas dans les compétitions.
</Note>

Si l'invite d'autorisation n'apparaît pas, ouvrez l'app Réglages sur votre iPhone (pas MoveTogether), faites défiler et appuyez sur **Santé**, appuyez sur **Accès aux données et appareils**, trouvez MoveTogether dans la liste et activez les catégories de données que vous voulez partager.

## Connecter d'autres trackers

Même processus pour Fitbit, Garmin, WHOOP, Oura, Strava, Polar, Suunto et Ultrahuman :

1. Ouvrez MoveTogether et allez dans **Réglages → Appareils connectés**.
2. Appuyez sur le nom de votre tracker.
3. Vous serez redirigé vers la page de connexion de votre tracker. Connectez-vous avec votre compte.
4. Vérifiez les autorisations et appuyez sur **Autoriser** pour autoriser MoveTogether.
5. Vos données commencent à se synchroniser. La première synchronisation peut prendre quelques minutes.

<Tip>
  Ouvrez l'app compagnon de votre tracker et laissez-la se synchroniser avec votre appareil avant de la connecter à MoveTogether. Ainsi, vos dernières données sont prêtes.
</Tip>

## Quelles données sont synchronisées ?

| Type de donnée | Utilisé pour |
|----------------|--------------|
| Pas | Score par nombre de pas, anneau de pas |
| Calories actives | Score par chiffres bruts, anneau de mouvement |
| Minutes d'exercice | Score basé sur les séances, anneau d'exercice |
| Séances | Score basé sur les séances, fil d'activité |

## À quelle fréquence les données se synchronisent ?

**Apple Watch :** en quelques minutes, puisque c'est lu directement depuis Apple Santé sur votre appareil. Une synchronisation en arrière-plan tourne aussi périodiquement pour garder les choses à jour quand vous n'utilisez pas activement l'application.

**Tous les autres trackers :** généralement toutes les 15 à 30 minutes. La fréquence exacte dépend de la fréquence à laquelle l'app compagnon de votre tracker se synchronise avec ses propres serveurs. Faites glisser vers le bas sur les écrans de classement pour demander les dernières données.

## Changer de tracker

Si vous obtenez un nouvel objet connecté ou voulez changer de tracker, allez dans **Réglages → Appareils connectés**, appuyez sur votre tracker actuel et sélectionnez **Déconnecter**, puis connectez votre nouvel appareil en suivant les étapes ci-dessus.

Votre historique de compétitions, vos récompenses et votre liste d'amis restent intacts. Seule l'activité future viendra du nouveau tracker.

## Puis-je connecter plusieurs trackers ?

Vous ne pouvez avoir qu'un seul tracker actif à la fois, pour éviter les données en double. Si vous changez d'appareil en pleine compétition, votre score reflètera l'activité combinée des deux trackers (données déjà enregistrées par votre ancien tracker, plus nouvelles données du nouveau tracker à partir de maintenant).
