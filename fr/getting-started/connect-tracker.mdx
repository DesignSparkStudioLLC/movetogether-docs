## Appareils pris en charge

MoveTogether fonctionne avec les plateformes de fitness suivantes via OpenWearables, notre partenaire d'intégration des données de santé :

| Appareil / Plateforme | Méthode de connexion |
|-------------------|-------------------|
| Apple Watch | Apple Santé (natif sur l'appareil) |
| Fitbit | Connexion OAuth |
| Garmin | Connexion OAuth |
| WHOOP | Connexion OAuth |
| Oura Ring | Connexion OAuth |
| Strava | Connexion OAuth |
| Polar | Connexion OAuth |
| Suunto | Connexion OAuth |
| Ultrahuman | Connexion OAuth |

## Comment fonctionnent les connexions

L'Apple Watch se connecte via Apple Santé. MoveTogether lit vos données fitness directement depuis l'app Santé de votre iPhone. Votre Apple Watch se synchronise toute seule avec Apple Santé, et MoveTogether lit à partir de là.

Tous les autres trackers se connectent via une connexion OAuth. Vous vous connectez au compte de votre tracker depuis MoveTogether, ce qui autorise l'app à synchroniser vos données fitness. Vos identifiants ne sont jamais stockés sur nos serveurs. La connexion passe par le système d'autorisation propre à votre tracker.

## Connecter l'Apple Watch

1. Ouvrez MoveTogether et allez dans **Réglages → Appareils connectés**.
2. Appuyez sur **Apple Watch**.
3. Une invite vous demande d'accorder à MoveTogether l'autorisation de lire vos données Apple Santé. Appuyez sur **Tout autoriser** (ou sélectionnez des catégories précises).
4. Votre activité commence à se synchroniser.

<Note>
  MoveTogether a besoin de l'accès en lecture aux catégories Apple Santé Pas, Énergie active (calories), Minutes d'exercice et Entraînements. Si vous refusez ces autorisations, votre activité n'apparaîtra pas dans les compétitions.
</Note>

Si l'invite n'apparaît pas, ouvrez l'app Réglages de votre iPhone (pas MoveTogether), faites défiler et appuyez sur **Santé**, appuyez sur **Accès aux données et appareils**, trouvez MoveTogether dans la liste et activez les catégories de données que vous souhaitez partager.

## Connecter d'autres trackers

Même procédure pour Fitbit, Garmin, WHOOP, Oura, Strava, Polar, Suunto et Ultrahuman :

1. Ouvrez MoveTogether et allez dans **Réglages → Appareils connectés**.
2. Appuyez sur le nom de votre tracker.
3. Vous serez redirigé vers la page de connexion de votre tracker. Connectez-vous avec votre compte.
4. Vérifiez les autorisations et appuyez sur **Autoriser** pour autoriser MoveTogether.
5. Vos données commencent à se synchroniser. La première synchronisation peut prendre quelques minutes.

<Tip>
  Ouvrez l'application compagnon de votre tracker et laissez-la se synchroniser avec votre appareil avant de la connecter à MoveTogether. Ainsi, vos dernières données sont prêtes.
</Tip>

## Quelles données se synchronisent ?

| Type de donnée | Utilisé pour |
|-----------|----------|
| Pas | Score Nombre de pas, anneau Pas |
| Calories actives | Score Chiffres bruts, anneau Mouvement |
| Minutes d'exercice | Score Entraînement, anneau Exercice |
| Entraînements | Score basé sur les entraînements, fil d'activité |

## À quelle fréquence les données se synchronisent-elles ?

**Apple Watch :** en quelques minutes, puisqu'elles sont lues directement depuis Apple Santé sur votre appareil. Une synchronisation en arrière-plan s'exécute aussi périodiquement pour tout maintenir à jour quand vous n'utilisez pas activement l'app.

**Tous les autres trackers :** généralement toutes les 15 à 30 minutes. La fréquence exacte dépend de la fréquence à laquelle l'app compagnon de votre tracker se synchronise avec ses propres serveurs. Tirez vers le bas sur les écrans de classement pour demander les dernières données.

## Changer de tracker

Si vous achetez un nouvel appareil ou souhaitez changer de tracker, allez dans **Réglages → Appareils connectés**, appuyez sur votre tracker actuel et sélectionnez **Déconnecter**, puis connectez votre nouvel appareil en suivant les étapes ci-dessus.

Votre historique de compétitions, vos récompenses et votre liste d'amis restent intacts. Seule l'activité future viendra du nouveau tracker.

## Puis-je connecter plusieurs trackers ?

Vous ne pouvez avoir qu'un seul tracker actif à la fois, pour éviter les données en double. Si vous changez d'appareil en plein milieu d'une compétition, votre score reflétera l'activité combinée des deux trackers (données déjà enregistrées par l'ancien plus les nouvelles données du nouveau à partir de maintenant).
