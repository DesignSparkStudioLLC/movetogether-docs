## Comment vous inscrire

1. Téléchargez MoveTogether depuis l'App Store.
2. Ouvrez l'application et appuyez sur **Commencer**.
3. Choisissez comment vous voulez créer votre compte :
   - **Se connecter avec Apple** utilise votre identifiant Apple. Option la plus rapide, et Apple peut masquer votre e-mail pour plus de confidentialité.
   - **Se connecter avec Google** utilise votre compte Google.
4. Lisez et acceptez les Conditions d'utilisation, la Politique de confidentialité et les Règles de la communauté. Appuyez sur chacune pour lire le texte complet avant d'accepter.
5. Choisissez un nom d'affichage et un nom d'utilisateur. Votre nom d'affichage est ce que les amis voient sur les classements. Votre nom d'utilisateur est ce que les gens utilisent pour vous trouver et vous ajouter.
6. Ajoutez une photo de profil (facultatif). Téléchargez depuis votre pellicule ou prenez-en une nouvelle. Vous pouvez la modifier plus tard dans les réglages du profil.

## Choisir un bon nom d'utilisateur

Votre nom d'utilisateur est unique et c'est ce que vos amis utilisent pour vous trouver. Gardez-le court et reconnaissable pour qu'on puisse vous chercher facilement. Les noms d'utilisateur peuvent inclure lettres, chiffres et soulignés. Vous pouvez changer votre nom d'utilisateur plus tard, mais vos amis devront chercher le nouveau.

## Ce qui se passe ensuite

Après l'inscription, l'application vous guide à travers un court flux d'intégration : connecter votre tracker fitness, définir vos objectifs et personnaliser votre expérience. C'est l'étape de configuration la plus importante. C'est ainsi que MoveTogether lit vos données d'activité pour que vous puissiez concourir.

Si vous sautez des étapes pendant l'intégration, vous pouvez les terminer plus tard dans les Réglages.
