MoveTogether est conçu autour du fait de montrer votre activité à vos amis. Le moyen le plus rapide de le faire est le **sélecteur de cartes de partage**.

## Cartes de partage du récap hebdomadaire

Quand votre **Rapport Hebdomadaire de Mo** est prêt, vous pouvez le partager dans l'un de trois styles de carte :

- **Carte de note** — votre note hebdomadaire (A à F) avec un arrière-plan d'ambiance correspondant.
- **Carte roast** — le regard impertinent de Coach Mo sur votre semaine, livré avec personnalité.
- **Carte d'anneaux** — un visuel épuré de vos fermetures d'anneaux à travers la semaine.

Faites défiler le sélecteur pour prévisualiser chaque style, puis appuyez sur **Partager** pour envoyer votre préféré.

## Les arrière-plans changent selon votre note

Les arrière-plans des cartes sont choisis selon votre performance :

| Note | Ambiance d'arrière-plan |
|-------|-----------------|
| A | Côte au lever du soleil |
| B | Montagne et sentiers |
| C | Aube urbaine |
| D | Brouillard matinal |
| F | Lumières de stade |

Une super semaine ressemble à une super semaine. Une semaine difficile a son propre visuel.

## Où partager

Appuyez sur **Partager** et la feuille de partage standard de votre téléphone s'ouvre. De là, vous pouvez publier sur Instagram, envoyer via iMessage, le déposer dans un chat de groupe ou enregistrer l'image dans votre pellicule.

## Comment les cartes sont générées

Les cartes sont rendues sur l'appareil en utilisant vos données réelles — votre nom, vos scores, votre semaine. Elles sont enregistrées sous forme d'images PNG, donc elles sont nettes sur n'importe quelle plateforme où vous les publiez.

<Note>
  Les cartes sont préchargées en arrière-plan dès que votre Rapport Hebdomadaire de Mo est prêt, pour que le sélecteur s'ouvre instantanément sans indicateur de chargement.
</Note>
