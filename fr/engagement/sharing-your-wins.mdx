MoveTogether est conçu pour montrer votre activité à vos amis. La façon la plus rapide de le faire est le **sélecteur de cartes de partage**.

## Cartes de partage du récap hebdomadaire

Quand votre **Rapport hebdomadaire Mo** est prêt, vous pouvez le partager dans l'un des trois styles de carte :

- **Carte de note** — votre note hebdomadaire (de A à F) avec un fond d'ambiance qui correspond.
- **Carte humoristique** — la vision irrévérencieuse de Coach Mo sur votre semaine, livrée avec personnalité.
- **Carte d'anneaux** — une visualisation propre de vos fermetures d'anneaux sur la semaine.

Faites défiler le sélecteur pour prévisualiser chaque style, puis touchez **Partager** pour envoyer votre préféré.

## Les fonds changent selon votre note

Les fonds des cartes sont choisis selon votre performance :

| Note | Ambiance du fond |
|-------|-----------------|
| A | Côte au lever du soleil |
| B | Montagne avec sentier |
| C | Aube urbaine |
| D | Brume matinale |
| F | Lumières de stade |

Une superbe semaine ressemble à une superbe semaine. Une semaine difficile a son propre visuel.

## Où partager

Touchez **Partager** et la feuille de partage standard de votre téléphone s'ouvre. À partir de là, vous pouvez publier sur Instagram, envoyer via iMessage, déposer dans un chat de groupe ou enregistrer l'image dans votre pellicule.

## Comment les cartes sont générées

Les cartes sont rendues sur l'appareil en utilisant vos vraies données : votre nom, vos scores, votre semaine. Elles sont enregistrées sous forme d'images PNG, donc elles sont nettes sur toute plateforme où vous les publiez.

<Note>
  Les cartes se préchargent en arrière-plan dès que votre rapport hebdomadaire Mo est prêt, donc le sélecteur s'ouvre instantanément sans indicateur de chargement.
</Note>
