MoveTogether est conçu autour du fait de montrer son activité à ses amis. La façon la plus rapide de le faire est le **sélecteur de cartes de partage**.

## Cartes de partage du récap hebdomadaire

Quand votre **Rapport Mo hebdomadaire** est prêt, vous pouvez le partager sous l'un des trois styles de carte :

- **Carte de note** — votre note hebdomadaire (de A à F) avec un fond d'ambiance qui correspond.
- **Roast card** — la vision irrévérencieuse de Coach Mo sur votre semaine, livrée avec personnalité.
- **Carte d'anneaux** — une visualisation propre de vos fermetures d'anneaux sur la semaine.

Faites glisser dans le sélecteur pour prévisualiser chaque style, puis appuyez sur **Partager** pour envoyer votre préférée.

## Les fonds changent avec votre note

Les fonds de cartes sont choisis selon votre performance :

| Note | Ambiance du fond |
|-------|-----------------|
| A | Côte au lever de soleil |
| B | Montagne avec sentier |
| C | Aube urbaine |
| D | Brouillard matinal |
| F | Lumières de stade |

Une super semaine ressemble à une super semaine. Une semaine difficile a son propre visuel.

## Où partager

Appuyez sur **Partager** et la feuille de partage standard de votre téléphone s'ouvre. De là, vous pouvez poster sur Instagram, envoyer via iMessage, le déposer dans un chat de groupe ou sauvegarder l'image dans votre pellicule.

## Comment les cartes sont générées

Les cartes sont rendues sur l'appareil en utilisant vos vraies données — votre nom, vos scores, votre semaine. Elles sont sauvegardées en images PNG, donc elles ont l'air nettes sur n'importe quelle plateforme où vous les publiez.

<Note>
  Les cartes sont préchargées en arrière-plan dès que votre Rapport Mo hebdomadaire est prêt, pour que le sélecteur s'ouvre instantanément sans roue de chargement.
</Note>
