MoveTogether est conçu pour que vous montriez votre activité à vos amis. Le moyen le plus rapide, c'est le **sélecteur de cartes partageables**.

## Cartes partageables du récap hebdomadaire

Quand votre **Rapport hebdomadaire de Mo** est prêt, vous pouvez le partager sous l'un de ces trois styles de carte :

- **Carte de note** — votre note hebdomadaire (A à F) avec un fond d'ambiance assorti.
- **Carte roast** — la vision irrévérencieuse de Coach Mo sur votre semaine, livrée avec sa personnalité.
- **Carte d'anneaux** — un visuel épuré de vos fermetures d'anneaux de la semaine.

Faites défiler le sélecteur pour prévisualiser chaque style, puis appuyez sur **Partager** pour envoyer votre préférée.

## Les fonds changent selon votre note

Les fonds des cartes sont choisis selon votre performance :

| Note | Ambiance du fond |
|-------|-----------------|
| A | Côte au lever du soleil |
| B | Montagne avec sentier |
| C | Aube urbaine |
| D | Brume matinale |
| F | Lumières du stade |

Une excellente semaine ressemble à une excellente semaine. Une semaine difficile a son propre visuel.

## Où partager

Appuyez sur **Partager** et la feuille de partage standard de votre téléphone s'ouvre. De là, vous pouvez publier sur Instagram, envoyer par iMessage, déposer dans un chat de groupe ou enregistrer l'image dans votre pellicule.

## Comment les cartes sont générées

Les cartes sont rendues sur l'appareil avec vos vraies données — votre nom, vos scores, votre semaine. Elles sont enregistrées en PNG, donc elles s'affichent nettement sur n'importe quelle plateforme.

<Note>
  Les cartes sont préchargées en arrière-plan dès que votre Rapport hebdomadaire de Mo est prêt, donc le sélecteur s'ouvre instantanément sans roue de chargement.
</Note>
