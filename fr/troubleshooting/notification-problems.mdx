---
title: "Problèmes de notification"
description: "Résoudre les problèmes avec les notifications push."
---

## Je ne reçois aucune notification

**Étape 1 : Vérifiez les paramètres de notification iOS.** Ouvrez **Réglages iPhone → MoveTogether → Notifications** et assurez-vous que **Autoriser les notifications** est activé avec vos styles d'alerte préférés activés.

**Étape 2 : Vérifiez les paramètres de notification dans l'application.** Ouvrez **MoveTogether → Paramètres → Notifications** et assurez-vous que les catégories que vous voulez sont activées.

**Étape 3 : Vérifiez le mode Concentration.** Si vous utilisez Ne pas déranger, Travail ou Sommeil, les notifications MoveTogether peuvent être silencieuses. Vérifiez vos paramètres Concentration pour autoriser MoveTogether.

**Étape 4 : Vérifiez le mode économie d'énergie.** Le mode économie d'énergie peut retarder les notifications push.

<Note>
  MoveTogether utilise la livraison de notifications provisoires par défaut. Si vous ne voyez que des notifications silencieuses dans votre Centre de notifications, touchez une fonctionnalité liée aux notifications dans l'application pour être invité à un accès complet aux notifications (sons, bannières et badges).
</Note>

## Je reçois trop de notifications

Allez dans **Paramètres → Notifications** dans MoveTogether et désactivez les catégories que vous ne voulez pas.
