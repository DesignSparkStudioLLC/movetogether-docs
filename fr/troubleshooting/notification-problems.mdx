## Je ne reçois aucune notification

**Étape 1 : Vérifiez les paramètres de notification iOS.** Ouvrez **Réglages iPhone → MoveTogether → Notifications** et assurez-vous que **Autoriser les notifications** est activé avec vos styles d'alerte préférés activés.

**Étape 2 : Vérifiez les paramètres de notification in-app.** Ouvrez **MoveTogether → Paramètres → Notifications** et assurez-vous que les catégories que vous voulez sont activées.

**Étape 3 : Vérifiez le mode Concentration.** Si vous utilisez Ne pas déranger, Travail ou Sommeil dans Concentration, les notifications MoveTogether peuvent être réduites au silence. Vérifiez vos paramètres Concentration pour autoriser le passage de MoveTogether.

**Étape 4 : Vérifiez le mode Économie d'énergie.** Le mode Économie d'énergie peut retarder les notifications push.

<Note>
  MoveTogether utilise la livraison de notifications provisoires par défaut. Si vous ne voyez que des notifications silencieuses dans votre Centre de notifications, appuyez sur une fonctionnalité liée aux notifications dans l'application pour qu'on vous demande l'accès complet aux notifications (sons, bannières et badges).
</Note>

## Je reçois trop de notifications

Allez dans **Paramètres → Notifications** dans MoveTogether et désactivez les catégories que vous ne voulez pas.
