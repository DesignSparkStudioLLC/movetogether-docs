## 支持的设备

MoveTogether 通过我们的健康数据集成合作伙伴 OpenWearables 支持以下健身平台:

| 设备 / 平台 | 连接方式 |
|-------------------|-------------------|
| Apple Watch | Apple 健康(设备原生) |
| Fitbit | OAuth 登录 |
| Garmin | OAuth 登录 |
| WHOOP | OAuth 登录 |
| Oura Ring | OAuth 登录 |
| Strava | OAuth 登录 |
| Polar | OAuth 登录 |
| Suunto | OAuth 登录 |
| Ultrahuman | OAuth 登录 |

## 连接的工作原理

Apple Watch 通过 Apple 健康连接。MoveTogether 直接从你 iPhone 上的健康应用读取你的健身数据。你的 Apple Watch 自行同步到 Apple 健康,MoveTogether 从那里读取。

所有其他追踪器通过 OAuth 登录连接。你在 MoveTogether 内登录到你的追踪器账户,从而授权应用同步你的健身数据。你的登录凭据从不存储在我们的服务器上。连接通过你的追踪器自身的授权系统进行。

## 连接 Apple Watch

1. 打开 MoveTogether 并进入**设置 → 已连接设备**。
2. 点击 **Apple Watch**。
3. 系统会提示你授予 MoveTogether 读取 Apple 健康数据的权限。点击**全部允许**(或选择特定类别)。
4. 你的活动开始同步。

<Note>
  MoveTogether 需要对 Apple 健康类别的读取权限,包括步数、活动能量(卡路里)、运动分钟数和锻炼。如果你拒绝这些权限,你的活动将不会出现在竞赛中。
</Note>

如果权限提示未出现,请打开 iPhone 上的设置应用(不是 MoveTogether),向下滚动并点击**健康**,点击**数据访问与设备**,在列表中找到 MoveTogether,并启用你想分享的数据类别。

## 连接其他追踪器

对于 Fitbit、Garmin、WHOOP、Oura、Strava、Polar、Suunto 和 Ultrahuman 流程相同:

1. 打开 MoveTogether 并进入**设置 → 已连接设备**。
2. 点击你的追踪器名称。
3. 你将被带到追踪器的登录页面。使用你的账户登录。
4. 查看权限并点击**允许**以授权 MoveTogether。
5. 你的数据开始同步。首次同步可能需要几分钟。

<Tip>
  在连接到 MoveTogether 之前,打开你的追踪器的伴侣应用并让它与你的设备同步。这样你最新的数据就准备好了。
</Tip>

## 哪些数据会同步?

| 数据类型 | 用途 |
|-----------|----------|
| 步数 | 步数计分,步数环 |
| 活动卡路里 | 原始数值计分,活动环 |
| 运动分钟数 | 锻炼计分,锻炼环 |
| 锻炼 | 基于锻炼的计分,活动动态 |

## 数据多久同步一次?

**Apple Watch:** 几分钟内,因为它直接从你设备上的 Apple 健康读取。后台同步也会定期运行,以便在你不积极使用应用时保持数据最新。

**所有其他追踪器:** 通常每 15 到 30 分钟一次。具体频率取决于你的追踪器伴侣应用与其自己的服务器的同步频率。在排行榜屏幕上下拉刷新以请求最新数据。

## 切换追踪器

如果你有了新的可穿戴设备或想切换追踪器,请进入**设置 → 已连接设备**,点击你当前的追踪器并选择**断开连接**,然后按照上述步骤连接你的新设备。

你的竞赛历史、成就和好友列表保持不变。只有未来的活动会来自新的追踪器。

## 我可以连接多个追踪器吗?

为防止数据重复,你一次只能有一个活动追踪器。如果你在竞赛中途切换设备,你的得分将反映两个追踪器的合并活动(已从旧追踪器记录的数据,加上从新追踪器开始的新数据)。
