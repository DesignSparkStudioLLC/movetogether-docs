## MoveTogether 收集哪些数据

**账户信息。** 你的姓名、电子邮件地址、用户名和个人资料照片，由你在创建账户时提供。

**健身数据。** 步数、活动卡路里、锻炼分钟和训练信息，从你连接的健身追踪器同步。

**比赛数据。** 你的比赛分数、排名和参与历史。

**使用数据。** 关于你如何使用应用的匿名分析，用于改进 MoveTogether。你可以在**设置 → 隐私**中选择退出。

## 你的健身数据如何处理

MoveTogether 将你的健身数据存储在我们的服务器上，以驱动应用的核心功能：排行榜、比赛、活动动态、成就等。对于 Apple Watch 用户，数据从你设备上的 Apple Health 读取并发送到我们的服务器。对于其他追踪器，数据通过我们的集成合作伙伴 OpenWearables 通过 OAuth 连接从追踪器提供商的服务器同步。

为了安全和公平，比赛分数在服务器端计算。你的健康数据保留在 Apple Health（或你追踪器的平台）中作为原始事实来源。MoveTogether 读取它。我们从不修改它。

## 谁可以看到你的数据？

比赛参与者可以在排行榜上看到你的比赛相关统计数据，受你的隐私设置约束。朋友可以在社交动态中看到你的活动，受你的隐私设置约束。MoveTogether 的系统处理你的数据以计算比赛分数并生成成就。我们从不出售你的个人信息或与第三方共享你的原始健康数据。

## AI 提供商看到什么

Coach Mo 和支持代理建立在第三方 AI 平台上。**我们在任何数据到达这些提供商之前编辑你的个人信息** — 你的姓名、朋友的姓名、电子邮件和用户名在传输前都被占位符替换。AI 提供商看到你的活动数字和统计数据，而不是你是谁。

要完整分解这是如何工作的，包括语音的诚实例外，请参阅 [AI 和你的数据](/account/ai-and-your-data)。

## 数据存储和安全

你的数据使用行业标准加密存储。你的设备和我们的服务器之间的所有连接都是加密的。比赛分数在服务器端计算以防止操纵。我们的安全模型意味着你的数据只能通过经过身份验证、验证的服务器请求访问。

## 下载你的数据

你可以请求 MoveTogether 拥有的关于你的所有数据的副本。前往**设置 → 隐私 → 下载我的数据**，点按按钮请求导出，当你的导出准备好时（通常在 24 到 48 小时内），你会收到带有下载链接的电子邮件。

## 删除你的数据

要删除你的账户和所有相关数据，前往**设置 → 隐私 → 删除我的账户**（或**设置 → 账户 → 删除账户**），如果被要求确认你的身份，并确认。这是永久性的，无法撤销。你的所有数据都将被删除。

## 第三方服务

MoveTogether 使用这些第三方服务来运营：

| 服务 | 目的 |
|---------|---------|
| Supabase | 数据库和服务器基础设施 |
| RevenueCat | 订阅管理 |
| OneSignal | 推送通知 |
| Anthropic Claude | 驱动 Coach Mo AI（仅接收匿名数据 — 请参阅 [AI 和你的数据](/account/ai-and-your-data)） |
| OpenWearables | 第三方追踪器的健康数据集成 |
| Hive | 内容审核（文本和图像） |
| Stream | 活动动态基础设施 |
| Sentry | 错误跟踪和性能监控 |
| Mixpanel | 匿名产品分析 |

每个服务都有自己的隐私政策。要了解完整详细信息，请阅读我们的[隐私政策](https://movetogetherfitness.com/privacy)。
