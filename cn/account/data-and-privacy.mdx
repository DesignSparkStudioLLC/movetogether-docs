## MoveTogether 收集哪些数据

**账户信息。** 你的姓名、电子邮件地址、用户名和个人资料照片,由你在创建账户时提供。

**健身数据。** 步数、活动卡路里、运动分钟数和锻炼信息,从你连接的健身追踪器同步。

**竞赛数据。** 你的竞赛分数、排名和参与历史。

**使用数据。** 关于你如何使用应用的匿名分析,用于改进 MoveTogether。你可以在**设置 → 隐私**中选择退出。

## 你的健身数据如何处理

MoveTogether 将你的健身数据存储在我们的服务器上,以驱动应用的核心功能:排行榜、竞赛、活动动态、成就等等。对于 Apple Watch 用户,数据从你设备上的 Apple 健康读取并发送到我们的服务器。对于其他追踪器,数据通过我们的集成合作伙伴 OpenWearables 的 OAuth 连接从追踪器提供商的服务器同步。

为了安全性和公平性,竞赛分数在服务器端计算。你的健康数据保留在 Apple 健康(或你追踪器的平台)中,作为原始的真实来源。MoveTogether 读取它。我们从不修改它。

## 谁可以看到你的数据?

竞赛参与者可以在排行榜上看到你与竞赛相关的统计数据,受你的隐私设置约束。朋友可以在社交动态中看到你的活动,受你的隐私设置约束。MoveTogether 的系统处理你的数据以计算竞赛分数和生成成就。我们从不出售你的个人信息或与第三方分享你的原始健康数据。

## 数据存储和安全

你的数据使用行业标准加密存储。你的设备和我们的服务器之间的所有连接都已加密。竞赛分数在服务器端计算以防止操纵。我们的安全模型意味着只能通过经过身份验证、已验证的服务器请求访问你的数据。

## 下载你的数据

你可以请求 MoveTogether 对你拥有的所有数据的副本。进入**设置 → 隐私 → 下载我的数据**,点击按钮请求导出,当你的导出准备好时(通常在 24 到 48 小时内),你会收到一封带有下载链接的电子邮件。

## 删除你的数据

要删除你的账户和所有关联数据,请进入**设置 → 隐私 → 删除我的账户**(或**设置 → 账户 → 删除账户**),如有要求确认你的身份,然后确认。这是永久性的,无法撤销。你的所有数据将被删除。

## 第三方服务

MoveTogether 使用这些第三方服务来运营:

| 服务 | 用途 |
|---------|---------|
| Supabase | 数据库和服务器基础设施 |
| RevenueCat | 订阅管理 |
| OneSignal | 推送通知 |
| Anthropic Claude | 为 Coach Mo AI 提供动力 |
| OpenWearables | 第三方追踪器的健康数据集成 |
| Hive | 内容审核(文本和图像) |
| Stream | 活动动态基础设施 |
| Sentry | 错误跟踪和性能监控 |
| Mixpanel | 匿名产品分析 |

每个服务都有自己的隐私政策。有关完整详细信息,请阅读我们的[隐私政策](https://movetogetherfitness.com/privacy)。
