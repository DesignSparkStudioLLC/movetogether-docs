## MoveTogether が収集するデータ

**アカウント情報。** アカウント作成時にあなたが提供する名前、メールアドレス、ユーザー名、プロフィール写真。

**フィットネスデータ。** 接続したフィットネストラッカーから同期される歩数、アクティブカロリー、エクササイズ分数、ワークアウト情報。

**コンペティションデータ。** コンペティションのスコア、ランキング、参加履歴。

**使用データ。** App の使い方に関する匿名分析、MoveTogether の改善に使用。**設定 → プライバシー** でオプトアウトできます。

## フィットネスデータの扱い

MoveTogether は App のコア機能（リーダーボード、コンペティション、アクティビティフィード、実績など）を動かすために、フィットネスデータをサーバーに保存します。Apple Watch ユーザーの場合、データはデバイス上の Apple ヘルスケアから読まれ、サーバーに送信されます。他のトラッカーでは、データは統合パートナーの OpenWearables を通じて OAuth 接続でトラッカープロバイダのサーバーから同期されます。

コンペティションのスコアは、安全性と公平性のためサーバー側で計算されます。あなたのヘルスデータは Apple ヘルスケア（またはトラッカーのプラットフォーム）に元の真実として残ります。MoveTogether はそれを読み取ります。決して変更しません。

## 誰があなたのデータを見られるか？

コンペティションの参加者は、プライバシー設定に従ってリーダーボード上でコンペティション関連の統計を見られます。友達は、プライバシー設定に従ってソーシャルフィードであなたのアクティビティを見られます。MoveTogether のシステムはコンペティションのスコア計算や実績生成のためにあなたのデータを処理します。私たちはあなたの個人情報を売ったり、生のヘルスデータを第三者と共有したりすることはありません。

## AI プロバイダが見るもの

Coach Mo とサポートエージェントは第三者の AI プラットフォーム上で作られています。**いずれのデータも各プロバイダに届く前に、あなたの個人情報を匿名化** します — 名前、友達の名前、メール、ユーザー名はすべて送信前にプレースホルダーに置き換えられます。AI プロバイダが見るのはあなたのアクティビティ数値や統計であって、あなたが誰かではありません。

これがどう機能するかの完全な内訳、音声の例外を含むものは [AI とあなたのデータ](/ja/account/ai-and-your-data) を見てください。

## データの保存とセキュリティ

データは業界標準の暗号化で保存されます。デバイスとサーバー間のすべての接続は暗号化されています。コンペティションのスコアは操作を防ぐためサーバー側で計算されます。私たちのセキュリティモデルにより、データは認証・検証済みのサーバーリクエストを通じてのみアクセスできます。

## データをダウンロードする

MoveTogether があなたについて持っているすべてのデータのコピーをリクエストできます。**設定 → プライバシー → 自分のデータをダウンロード** に進み、エクスポートをリクエストするボタンをタップすると、エクスポートの準備ができたとき（通常 24〜48 時間以内）にダウンロードリンクのメールが届きます。

## データを削除する

アカウントと関連するすべてのデータを削除するには、**設定 → プライバシー → 自分のアカウントを削除**（または **設定 → アカウント → アカウントを削除**）に進み、求められれば本人確認をして確定します。これは恒久的で、取り消せません。あなたのすべてのデータが削除されます。

## 第三者サービス

MoveTogether は次の第三者サービスを使って運用されています：

| サービス | 目的 |
|----------|------|
| Supabase | データベースとサーバーインフラ |
| RevenueCat | サブスクリプション管理 |
| OneSignal | プッシュ通知 |
| Anthropic Claude | Coach Mo AI を動かす（匿名化されたデータのみ受信 — [AI とあなたのデータ](/ja/account/ai-and-your-data) を参照） |
| OpenWearables | 第三者トラッカーのヘルスデータ統合 |
| Hive | コンテンツモデレーション（テキストと画像） |
| Stream | アクティビティフィードのインフラ |
| Sentry | エラートラッキングとパフォーマンス監視 |
| Mixpanel | 匿名のプロダクト分析 |

各サービスにはそれぞれのプライバシーポリシーがあります。詳細は私たちの [プライバシーポリシー](https://movetogetherfitness.com/privacy) を読んでください。
