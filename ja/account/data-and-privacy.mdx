## MoveTogether が収集するデータ

**アカウント情報。** 名前、メールアドレス、ユーザー名、プロフィール写真。アカウントを作成するときに提供されます。

**フィットネスデータ。** 歩数、アクティブカロリー、運動分、ワークアウト情報。接続されたフィットネストラッカーから同期されます。

**競争データ。** 競争スコア、ランキング、参加履歴。

**使用データ。** アプリの使用方法に関する匿名分析。MoveTogether を改善するために使用されます。**設定 → プライバシー**でオプトアウトできます。

## フィットネスデータの処理方法

MoveTogether は、リーダーボード、競争、アクティビティフィード、アチーブメントなど、アプリのコア機能を強化するために、サーバーにフィットネスデータを保存します。Apple Watch ユーザーの場合、データはデバイスの Apple ヘルスケアから読み取られ、サーバーに送信されます。他のトラッカーの場合、データは統合パートナーである OpenWearables を通じて、OAuth 接続を介してトラッカープロバイダーのサーバーから同期されます。

セキュリティと公平性のために、競争スコアはサーバー側で計算されます。健康データは、元の真実のソースとして Apple ヘルスケア(またはトラッカーのプラットフォーム)に残ります。MoveTogether はそれを読み取ります。私たちはそれを決して変更しません。

## 誰があなたのデータを見ることができますか?

競争参加者は、プライバシー設定の対象として、リーダーボードで競争関連の統計を見ることができます。友達は、プライバシー設定の対象として、ソーシャルフィードであなたのアクティビティを見ることができます。MoveTogether のシステムは、競争スコアを計算し、アチーブメントを生成するためにデータを処理します。個人情報を販売したり、生の健康データを第三者と共有したりすることはありません。

## データストレージとセキュリティ

データは、業界標準の暗号化を使用して保存されます。デバイスとサーバー間のすべての接続は暗号化されています。競争スコアは、操作を防ぐためにサーバー側で計算されます。当社のセキュリティモデルは、認証された検証済みのサーバーリクエストを通じてのみデータにアクセスできることを意味します。

## データのダウンロード

MoveTogether があなたに関して持っているすべてのデータのコピーをリクエストできます。**設定 → プライバシー → 私のデータをダウンロード**に移動し、ボタンをタップしてエクスポートをリクエストすると、エクスポートが準備できたとき(通常 24〜48 時間以内)にダウンロードリンク付きのメールが届きます。

## データの削除

アカウントとすべての関連データを削除するには、**設定 → プライバシー → 私のアカウントを削除**(または**設定 → アカウント → アカウントを削除**)に移動し、求められた場合は身元を確認し、確認します。これは永久的であり、元に戻すことはできません。すべてのデータが削除されます。

## サードパーティサービス

MoveTogether は、運営のためにこれらのサードパーティサービスを使用します:

| サービス | 目的 |
|---------|---------|
| Supabase | データベースとサーバーインフラストラクチャ |
| RevenueCat | サブスクリプション管理 |
| OneSignal | プッシュ通知 |
| Anthropic Claude | Coach Mo AI を動かす |
| OpenWearables | サードパーティトラッカーのヘルスデータ統合 |
| Hive | コンテンツモデレーション(テキストと画像) |
| Stream | アクティビティフィードインフラストラクチャ |
| Sentry | エラー追跡とパフォーマンス監視 |
| Mixpanel | 匿名製品分析 |

各サービスには独自のプライバシーポリシーがあります。詳細については、[プライバシーポリシー](https://movetogetherfitness.com/privacy)を読んでください。
