## MoveTogether が収集するデータ

**アカウント情報。** 名前、メールアドレス、ユーザー名、プロフィール写真。アカウント作成時にあなたが提供したもの。

**フィットネスデータ。** 接続されたフィットネストラッカーから同期される歩数、アクティブカロリー、運動時間、ワークアウト情報。

**コンペティションデータ。** コンペティションのスコア、ランキング、参加履歴。

**使用データ。** アプリの使用方法に関する匿名分析。MoveTogether の改善に使用されます。**設定 → プライバシー** でオプトアウトできます。

## フィットネスデータの扱い方

MoveTogether はアプリのコア機能(リーダーボード、コンペティション、アクティビティフィード、アチーブメントなど)を動かすために、フィットネスデータを当社のサーバーに保存します。Apple Watch ユーザーの場合、データはデバイス上の Apple ヘルスケアから読み取られ、サーバーに送信されます。他のトラッカーの場合、統合パートナーである OpenWearables を経由する OAuth 接続を通じて、トラッカープロバイダーのサーバーからデータが同期されます。

コンペティションのスコアはセキュリティと公平性のためサーバー側で計算されます。ヘルスデータは元の信頼できるソースとして Apple ヘルスケア(またはトラッカーのプラットフォーム)に残ります。MoveTogether はそれを読み取ります。決して変更しません。

## あなたのデータを見られるのは誰?

コンペティション参加者は、あなたのプライバシー設定に従い、リーダーボード上でコンペティション関連の統計を見られます。友達は、あなたのプライバシー設定に従い、ソーシャルフィードであなたのアクティビティを見られます。MoveTogether のシステムは、コンペティションスコアを計算してアチーブメントを生成するためにあなたのデータを処理します。当社は決して個人情報を販売せず、生のヘルスデータを第三者と共有しません。

## AI プロバイダーが見るもの

Coach Mo とサポートエージェントは、サードパーティの AI プラットフォーム上に構築されています。**プロバイダーに到達する前にあなたの個人情報を編集します** — あなたの名前、友達の名前、メール、ユーザー名はすべて送信前にプレースホルダーで置き換えられます。AI プロバイダーは、あなたのアクティビティ数値と統計を見ますが、あなたが誰かは見ません。

これがどのように機能するかの完全な内訳(音声の正直な例外を含む)については、[AI とあなたのデータ](/ja/account/ai-and-your-data) を参照してください。

## データの保存とセキュリティ

データは業界標準の暗号化で保存されます。デバイスと当社のサーバー間のすべての接続は暗号化されています。コンペティションスコアは操作を防ぐためサーバー側で計算されます。当社のセキュリティモデルは、データが認証済み、検証済みのサーバーリクエスト経由でのみアクセス可能であることを意味します。

## データのダウンロード

MoveTogether があなたについて持つすべてのデータのコピーをリクエストできます。**設定 → プライバシー → データをダウンロード** に移動し、ボタンをタップしてエクスポートをリクエストします。エクスポートの準備ができたら(通常 24〜48 時間以内)、ダウンロードリンク付きのメールが届きます。

## データの削除

アカウントと関連するすべてのデータを削除するには、**設定 → プライバシー → アカウントを削除**(または **設定 → アカウント → アカウントを削除**)に移動し、求められれば本人確認を行い、確定します。これは永続的で元に戻せません。すべてのデータが削除されます。

## サードパーティのサービス

MoveTogether は運営のために以下のサードパーティサービスを利用しています:

| サービス | 用途 |
|---------|---------|
| Supabase | データベースとサーバーインフラ |
| RevenueCat | サブスクリプション管理 |
| OneSignal | プッシュ通知 |
| Anthropic Claude | Coach Mo AI を支える(匿名化されたデータのみを受信 — [AI とあなたのデータ](/ja/account/ai-and-your-data) を参照) |
| OpenWearables | サードパーティトラッカーのヘルスデータ統合 |
| Hive | コンテンツモデレーション(テキストおよび画像) |
| Stream | アクティビティフィードのインフラ |
| Sentry | エラー追跡とパフォーマンスモニタリング |
| Mixpanel | 匿名のプロダクト分析 |

各サービスには独自のプライバシーポリシーがあります。完全な詳細は [プライバシーポリシー](https://movetogetherfitness.com/privacy) をお読みください。
