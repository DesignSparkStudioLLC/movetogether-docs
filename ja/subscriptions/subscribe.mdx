## 初めてサブスクライブする

1. MoveTogether を開き、**設定 → サブスクリプション**に移動するか(または Pro 機能を使用しようとしたときに表示されるアップグレードプロンプトをタップします)。
2. 価格と機能が一覧表示された Pro プランが表示されます。
3. 請求期間(月次または年次)を選択します。
4. App Store を通じて購入を確認します。Face ID、Touch ID、または Apple ID パスワードで認証する必要がある場合があります。
5. プランはすぐにアクティブになり、Pro 機能がすぐにアンロックされます。

## Web 購入

[movetogetherfitness.com](https://movetogetherfitness.com) の Web サイトを通じてサブスクライブすることもできます。価格が異なる可能性のある代替の購入パス。サブスクリプションは、どこで購入したかに関係なく、自動的にアプリと同期します。

## 紹介価格

紹介またはプロモーション価格が表示される場合は、購入前にサブスクリプション画面に表示されます。紹介価格は新規サブスクライバーのみに適用され、プロモーション期間が終了した後は標準料金で更新されます。

## 無料トライアル

MoveTogether は、随時 Pro プランの無料トライアルを提供する場合があります。トライアルが利用可能な場合は、サブスクリプション画面に表示されます。事前にキャンセルしない限り、トライアル期間の終了時に有料サブスクリプションに変換されます。
