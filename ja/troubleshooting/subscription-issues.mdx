title: "サブスクリプションの問題"
description: "MoveTogether サブスクリプションの問題を解決する方法 — 加入後も Pro 機能がロックされている、課金後にサブスクリプションが見えない、購入の復元。"
---

## 加入したけど機能がまだロックされている

1. MoveTogether を強制終了して再度開き、サブスクリプション状態のチェックをトリガーします。
2. 1〜2 分待ちます。App Store が購入を確認してから App が認識するまでに少し遅延があることがあります。
3. **設定 → サブスクリプション** でサブスクリプション状態を確認します。
4. **設定 → サブスクリプション** で **購入を復元** をタップします。
5. Apple 側でサブスクリプションがアクティブかを確認します：**iPhone 設定 → [あなたの名前] → サブスクリプション**。

サブスクリプションがアクティブだと確認できたのに機能がまだロックされている場合は、[movetogetherfitness.com](https://movetogetherfitness.com) で Mo にチャットしてください。

## 課金されたがサブスクリプションが見えない

- 購入に使ったのと同じ Apple ID でサインインしていることを確認します。
- **購入を復元** ボタンを試します。

問題が続く場合は、Apple ID と課金のスクリーンショットとともに [movetogetherfitness.com](https://movetogetherfitness.com) で Mo にチャットしてください。
