## サブスクライブしましたが機能がまだロックされています

1. サブスクリプションステータスチェックをトリガーするには、MoveTogether を強制終了して再度開きます。
2. 1〜2 分待ちます。App Store が購入を確認することとアプリがそれを認識することの間に短い遅延がある場合があります。
3. **設定 → サブスクリプション**でサブスクリプションステータスを確認します。
4. **設定 → サブスクリプション**で**購入を復元**をタップします。
5. Apple 側でサブスクリプションがアクティブであることを確認します:**iPhone 設定 → [あなたの名前] → サブスクリプション**。

サブスクリプションがアクティブであることを確認しているが、機能がまだロックされている場合は、[movetogetherfitness.com](https://movetogetherfitness.com) で Mo とチャットしてください。

## 請求されましたが、サブスクリプションが表示されません

- 購入に使用したのと同じ Apple ID でサインインしていることを確認します。
- **購入を復元**ボタンを試してください。

問題が続く場合は、Apple ID と請求のスクリーンショットを持って、[movetogetherfitness.com](https://movetogetherfitness.com) で Mo とチャットしてください。
