## サポートされているデバイス

MoveTogether は、ヘルスデータ統合パートナーである OpenWearables を通じて、以下のフィットネスプラットフォームと連携します:

| デバイス / プラットフォーム | 接続方法 |
|-------------------|-------------------|
| Apple Watch | Apple ヘルスケア(デバイスネイティブ) |
| Fitbit | OAuth サインイン |
| Garmin | OAuth サインイン |
| WHOOP | OAuth サインイン |
| Oura Ring | OAuth サインイン |
| Strava | OAuth サインイン |
| Polar | OAuth サインイン |
| Suunto | OAuth サインイン |
| Ultrahuman | OAuth サインイン |

## 接続の仕組み

Apple Watch は Apple ヘルスケアを通じて接続します。MoveTogether は iPhone のヘルスケアアプリから直接フィットネスデータを読み取ります。Apple Watch は自動的に Apple ヘルスケアと同期し、MoveTogether はそこから読み取ります。

他のすべてのトラッカーは OAuth サインインを通じて接続します。MoveTogether 内でトラッカーのアカウントにサインインし、フィットネスデータを同期するためにアプリを承認します。ログイン認証情報がサーバーに保存されることはありません。接続はトラッカー自身の認証システムを通じて実行されます。

## Apple Watch の接続

1. MoveTogether を開き、**設定 → 接続済みデバイス**に移動します。
2. **Apple Watch** をタップします。
3. MoveTogether に Apple ヘルスケアデータを読み取る権限を付与するように求めるプロンプトが表示されます。**すべて許可**をタップする(または特定のカテゴリを選択する)。
4. アクティビティの同期が始まります。

<Note>
  MoveTogether は、歩数、アクティブエネルギー(カロリー)、運動分、ワークアウトを含む Apple ヘルスケアカテゴリへの読み取りアクセスを必要とします。これらの権限を拒否すると、競争にアクティビティが表示されません。
</Note>

権限プロンプトが表示されない場合は、iPhone の設定アプリを開き(MoveTogether ではありません)、下にスクロールして**ヘルスケア**をタップし、**データアクセスとデバイス**をタップして、リストから MoveTogether を見つけ、共有したいデータカテゴリを有効にしてください。

## 他のトラッカーの接続

Fitbit、Garmin、WHOOP、Oura、Strava、Polar、Suunto、Ultrahuman の場合も同じプロセスです:

1. MoveTogether を開き、**設定 → 接続済みデバイス**に移動します。
2. トラッカーの名前をタップします。
3. トラッカーのログインページに移動します。アカウントでサインインしてください。
4. 権限を確認し、**許可**をタップして MoveTogether を承認します。
5. データの同期が始まります。最初の同期には数分かかることがあります。

<Tip>
  MoveTogether に接続する前に、トラッカーのコンパニオンアプリを開き、デバイスと同期させてください。そうすれば、最新のデータが準備できます。
</Tip>

## どのデータが同期されるか?

| データタイプ | 使用目的 |
|-----------|----------|
| 歩数 | 歩数スコアリング、歩数リング |
| アクティブカロリー | 生の数値スコアリング、ムーブリング |
| 運動分 | ワークアウトスコアリング、エクササイズリング |
| ワークアウト | ワークアウトベースのスコアリング、アクティビティフィード |

## データはどのくらいの頻度で同期されますか?

**Apple Watch:** デバイスの Apple ヘルスケアから直接読み取られるため、数分以内に同期されます。アプリをアクティブに使用していないときも、バックグラウンド同期が定期的に実行され、状況を最新に保ちます。

**他のすべてのトラッカー:** 通常 15〜30 分ごと。正確な頻度は、トラッカーのコンパニオンアプリが自身のサーバーと同期する頻度によって異なります。リーダーボード画面で下に引っ張って更新し、最新のデータをリクエストしてください。

## トラッカーの切り替え

新しいウェアラブルを入手するか、トラッカーを切り替えたい場合は、**設定 → 接続済みデバイス**に移動し、現在のトラッカーをタップして**切断**を選択し、上記の手順を使用して新しいデバイスを接続してください。

競争履歴、アチーブメント、友達リストはそのまま残ります。今後のアクティビティだけが新しいトラッカーから来ます。

## 複数のトラッカーを接続できますか?

データの重複を防ぐため、一度にアクティブなトラッカーを 1 つしか持つことができません。競争中にデバイスを切り替えると、スコアは両方のトラッカーからの結合アクティビティ(古いトラッカーから既に記録されたデータと、新しいトラッカーから今後の新しいデータ)を反映します。
