## 対応デバイス

MoveTogether は、ヘルスデータ統合パートナーである OpenWearables を通じて、次のフィットネスプラットフォームと連携します：

| デバイス／プラットフォーム | 接続方法 |
|---------------------------|---------|
| Apple Watch | Apple ヘルスケア（デバイス内ネイティブ） |
| Fitbit | OAuth サインイン |
| Garmin | OAuth サインイン |
| WHOOP | OAuth サインイン |
| Oura Ring | OAuth サインイン |
| Strava | OAuth サインイン |
| Polar | OAuth サインイン |
| Suunto | OAuth サインイン |
| Ultrahuman | OAuth サインイン |

## 接続のしくみ

Apple Watch は Apple ヘルスケアを介して接続します。MoveTogether は iPhone の「ヘルスケア」App から直接フィットネスデータを読み込みます。Apple Watch は自動的に Apple ヘルスケアと同期し、MoveTogether はそこから読み取ります。

他のすべてのトラッカーは OAuth サインインで接続します。MoveTogether 内でトラッカーのアカウントにサインインすると、App がフィットネスデータを同期する許可が与えられます。あなたのログイン情報がサーバーに保存されることはありません。接続はトラッカー自身の認可システムを通じて行われます。

## Apple Watch を接続する

1. MoveTogether を開いて **設定 → 接続済みデバイス** に進みます。
2. **Apple Watch** をタップ。
3. MoveTogether に Apple ヘルスケアのデータを読み込む許可を求めるプロンプトが表示されます。**すべて許可** をタップ（または特定のカテゴリを選択）。
4. アクティビティの同期が始まります。

<Note>
  MoveTogether は、歩数、アクティブエネルギー（カロリー）、エクササイズ分数、ワークアウトを含む Apple ヘルスケアのカテゴリへの読み取りアクセスが必要です。これらの権限を拒否すると、あなたのアクティビティはコンペティションに表示されません。
</Note>

権限プロンプトが表示されない場合は、iPhone の「設定」App を開き（MoveTogether ではありません）、下にスクロールして **ヘルスケア** をタップし、**データのアクセスとデバイス** をタップし、リストから MoveTogether を見つけ、共有したいデータカテゴリを有効化してください。

## 他のトラッカーを接続する

Fitbit、Garmin、WHOOP、Oura、Strava、Polar、Suunto、Ultrahuman も同じ手順です：

1. MoveTogether を開いて **設定 → 接続済みデバイス** に進みます。
2. トラッカーの名前をタップ。
3. トラッカーのログインページに移動します。アカウントでサインインします。
4. 権限を確認し、**許可** をタップして MoveTogether を認可します。
5. データの同期が始まります。初回の同期には数分かかることがあります。

<Tip>
  MoveTogether に接続する前に、トラッカーのコンパニオン App を開いてデバイスと同期させておきましょう。これで最新のデータが準備できます。
</Tip>

## どんなデータが同期されますか？

| データの種類 | 用途 |
|-------------|------|
| 歩数 | 歩数の採点、歩数リング |
| アクティブカロリー | 生数値の採点、ムーブリング |
| エクササイズ分数 | トレーニングの採点、エクササイズリング |
| ワークアウト | トレーニングベースの採点、アクティビティフィード |

## データはどれくらいの頻度で同期されますか？

**Apple Watch：** デバイス上の Apple ヘルスケアから直接読まれるため、数分以内です。バックグラウンドの同期も定期的に走り、App を積極的に使っていないときも最新の状態を保ちます。

**他のすべてのトラッカー：** 通常は 15〜30 分ごとです。正確な頻度は、トラッカーのコンパニオン App が自身のサーバーと同期する頻度によります。リーダーボード画面で下にスワイプして引っ張ると、最新データをリクエストできます。

## トラッカーを切り替える

新しいウェアラブルを入手したり、トラッカーを切り替えたりする場合は、**設定 → 接続済みデバイス** に進み、現在のトラッカーをタップして **切断** を選択し、上の手順で新しいデバイスを接続します。

コンペティション履歴、実績、友達リストはそのまま残ります。今後のアクティビティだけが新しいトラッカーから来ます。

## 複数のトラッカーを接続できますか？

データの重複を避けるため、アクティブなトラッカーは一度に 1 つだけにできます。コンペティション中にデバイスを切り替えると、スコアは両方のトラッカーの合算されたアクティビティを反映します（古いトラッカーで既に記録されたデータ + ここから先の新しいトラッカーからの新規データ）。
